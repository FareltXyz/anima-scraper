AnimaScraper Documentation

Official developer documentation for AnimaScraper: high-speed anime metadata and video streaming aggregator. Featuring complete MyAnimeList global metadata, Sokuja ID & Sakunime multi-server video streams (HLS & Embed), multi-language subtitles & direct downloads, plus automated bridging via MyAnimeList Numeric IDs. Dokumentasi resmi untuk Node.js library dan REST API service anime scraper berkecepatan tinggi. Mendukung metadata lengkap dari MyAnimeList, streaming video multi-server (HLS & Embed) serta unduhan Subtitle Indonesia dari Sokuja ID dan Sakunime, dilengkapi bridging otomatis menggunakan MyAnimeList Numeric ID.

1 Overview & Architecture Pengenalan & Arsitektur

AnimaScraper is engineered as a modern anime scraping solution that blends the performance of a native Node.js library with the simplicity of an out-of-the-box Express.js REST API. It bridges global English anime metadata from MyAnimeList and Indonesian fansub streaming portals (Sokuja ID) seamlessly without external API keys. AnimaScraper dirancang sebagai solusi scraper modern yang menggabungkan fleksibilitas library lokal Node.js dan kehandalan REST API siap pakai (Express.js). Layanan ini memecahkan masalah integrasi data anime antara sumber global berbahasa Inggris (MyAnimeList) dan portal streaming lokal Indonesia (Sokuja ID) secara transparan tanpa perlu mendaftar API key pihak ketiga.

Core Architecture Pipeline Node.js + Cheerio Engine
MyAnimeList Provider

Worldwide anime database: scores, synopsis, characters, voice actors, schedules, and studios. Database anime dunia: skor, sinopsis, karakter, seiyuu, jadwal & studio animasi.

MAL Linker Bridge

Heuristic title normalization, Roman numeral detection & fuzzy cross-matching to Sokuja & Sakunime. Normalisasi judul heuristik, deteksi angka romawi & jembatan otomatis ke Sokuja & Sakunime.

Sokuja ID Provider

Multi-server video embed streaming & direct download links grouped by resolution (360p - 1080p). Streaming embed video multi-mirror & tautan unduhan langsung per resolusi (360p - 1080p).

Sakunime Provider

3-Server aggregator (hid~, sm~, otaku) with 1080p HLS, AI Indo/Eng subtitles & downloads. Agregator 3 server (hid~, sm~, otaku) dengan HLS 1080p, subtitle Indo/Eng & unduhan.

2 Key Features Fitur Utama

Dual Interface (REST API & Node.js SDK)

Run as a standalone HTTP REST service or directly import JavaScript class modules in your Node.js apps without extra server overhead. Jalankan sebagai standalone HTTP REST server atau import langsung modul class JavaScript di proyek Node.js Anda tanpa overhead server terpisah.

Universal MAL ID Linking

Access both Sokuja ID and Sakunime anime & episode streams directly using numeric MyAnimeList IDs (e.g. 52991 for Sousou no Frieren) without knowing fansub or server slugs. Akses anime dan streaming episode Sokuja ID maupun Sakunime langsung memakai MyAnimeList Numeric ID (contoh: 52991 untuk Sousou no Frieren) tanpa perlu menghafal slug.

Streaming Mirrors & Direct Downloads

Extract embedded video players (Blogger, Google Drive, StreamSB, Vidhide, Mp4Upload) and direct download mirrors categorized by resolution (360p to 1080p). Mengekstrak iframe pemutar video (Blogger, Google Drive, StreamSB, Vidhide, Mp4Upload) serta link unduhan langsung per resolusi (360p hingga 1080p).

Resilient Parser & Zero API Key

No third-party API keys or accounts needed. Equipped with realistic desktop user-agent rotation, timeout guards, and structured JSON normalization. Tidak membutuhkan pendaftaran API key pihak ketiga. Dilengkapi rotasi header desktop realistis, guard timeout, dan normalisasi JSON bersih.

4 Quickstart Guide

Choose how you want to interact with AnimaScraper based on your architecture: Pilih cara tercepat menggunakan AnimaScraper sesuai kebutuhan proyek Anda:

Option A: Using REST API (cURL / HTTP) Cara A: Sebagai REST API (cURL / HTTP) Universal 
# 1. Health check
curl http://localhost:3000/health

# 2. Search anime on MyAnimeList
curl "http://localhost:3000/api/v1/myanimelist/search?q=frieren&page=1"

# 3. Stream & download episode 1 directly using MAL ID (52991)
curl http://localhost:3000/api/v1/sokujaId/52991/episode/1

# 4. Query Sakunime directly via MyAnimeList ID (52991) or prefixed slug (hid~)
curl http://localhost:3000/api/v1/sakunime/52991
curl http://localhost:3000/api/v1/sakunime/52991/episode/1
Option B: Using as Node.js Library (In-App) Cara B: Sebagai Node.js Library Direct In-App 
const { AnimaScraper } = require('./scraper');

async function main() {
  // Initialize MyAnimeList provider
  const mal = new AnimaScraper({ provider: 'myanimelist' });
  const searchResults = await mal.search('Frieren', { page: 1 });
  console.log('Top match:', searchResults.results[0]);

  // Initialize Sokuja ID provider
  const sokuja = new AnimaScraper({ provider: 'sokujaId' });
  const episodeStream = await sokuja.getEpisodeByMalId(52991, 1);
  console.log('Sokuja Player:', episodeStream.defaultStreamUrl);

  // Initialize Sakunime provider (Direct MAL ID Linking OR Prefixed Slugs)
  const sakunime = new AnimaScraper({ provider: 'sakunime' });
  const sakuEp = await sakunime.getAnimeEpisode(52991, 1);
  console.log('Sakunime HLS:', sakuEp.hlsUrl, 'Subtitles:', sakuEp.subtitles.length);
}

main().catch(console.error);

6 Node.js SDK Usage

To use the scraper directly in Node.js without calling the local HTTP server, import modules from the scraper directory: Untuk menggunakan scraper langsung di aplikasi Node.js tanpa memanggil HTTP server lokal, Anda dapat meng-import modul dari folder scraper:

1. AnimaScraper Factory

const { AnimaScraper } = require('./scraper');

// MyAnimeList Provider
const mal = new AnimaScraper({ provider: 'myanimelist' });

// Sokuja ID Provider
const sokuja = new AnimaScraper({ provider: 'sokujaId' });

// Sakunime Provider
const sakunime = new AnimaScraper({ provider: 'sakunime' });

2. Using Direct Provider Classes 2. Menggunakan Direct Provider Classes 

const { MyAnimeList, SokujaId, Sakunime, MalSokujaLinker, MalSakunimeLinker } = require('./scraper');

// Custom instances with specific options
const malDirect = new MyAnimeList({ baseUrl: 'https://myanimelist.net', timeout: 15000 });
const sokujaDirect = new SokujaId({ baseUrl: 'https://x6.sokuja.uk', timeout: 15000 });
const sakunimeDirect = new Sakunime({ baseUrl: 'https://sakunime.com', timeout: 20000 });

// Direct MAL-to-Sakunime resolution
const sakuLinker = new MalSakunimeLinker({ sakunimeProvider: sakunimeDirect, malProvider: malDirect });
const resolved = await sakuLinker.resolveMalId(52991);
console.log(resolved.slug); // 'hid~frieren-beyond-journeys-end-154587'

3. Error Handling with ScraperError 3. Error Handling dengan ScraperError 

const { AnimaScraper, ScraperError } = require('./scraper');
const scraper = new AnimaScraper({ provider: 'myanimelist' });

try {
  const anime = await scraper.getAnimeById(99999999);
} catch (error) {
  if (error instanceof ScraperError) {
    console.error(`HTTP Status: ${error.status}`);
    console.error(`Message: ${error.message}`);
  } else {
    console.error('System / Network Error:', error.message);
  }
}

10 Cross-Provider MAL Bridge System

Both MalSokujaLinker and MalSakunimeLinker automatically resolve MyAnimeList numeric IDs to Sokuja ID and Sakunime slugs despite title differences (such as appended Subtitle Indonesia, server prefixes hid~ / sm~, Roman numerals II / III, or Part 2 / Cour 2). Baik MalSokujaLinker maupun MalSakunimeLinker secara otomatis menerjemahkan ID numerik MyAnimeList ke slug Sokuja ID dan Sakunime meskipun terdapat perbedaan format penamaan (seperti imbuhan Subtitle Indonesia, awalan server hid~ / sm~, angka romawi II / III, maupun Part 2 / Cour 2).

Deterministic ID Bridge + 5-Phase Heuristic Matching Engine:

  1. Exact MAL ↔ AniList ↔ Sakunime Bridge: Sakunime Server 1 (hid~) slugs embed the AniList ID (e.g. hid~frieren-beyond-journeys-end-154587). MalSakunimeLinker resolves MAL ID ↔ AniList ID deterministically with confidence: 1.0 in both directions! Slug Sakunime Server 1 (hid~) memuat AniList ID di bagian akhir (mis. hid~frieren-beyond-journeys-end-154587). MalSakunimeLinker memetakan MAL ID ↔ AniList ID secara deterministik (confidence: 1.0) dua arah!
  2. Title Token Normalization: Cleans stop-words (e.g. "sub indo", "subtitle indonesia") and excludes single-episode / batch RAR posts. Membersihkan kata henti ("sub indo", "subtitle indonesia") serta menyaring post episode tunggal maupun arsip batch RAR.
  3. Roman Numeral, Season & Part Detection: Converts Roman numerals (e.g. Mushoku Tensei II) into season numbers and detects Season 2, Part 2, Zenpen, and Kouhen. Mengubah angka romawi (e.g. Mushoku Tensei II) menjadi nomor season serta mendeteksi Season 2, Part 2, Zenpen, dan Kouhen.
  4. Aired Year Cross-Validation: Verifies release years against MyAnimeList premiere dates to prevent false positives with reboots or sequels. Memverifikasi tahun rilis dari data MyAnimeList untuk mencegah false positive pada judul remake/sequel.
  5. Dice Similarity & Multi-Server Ranking: Calculates token overlap score across Sokuja ID and Sakunime Server 2/3 (?server=sm / ?server=otaku) while returning cross-server alternatives. Menghitung skor kemiripan token pada Sokuja ID serta Sakunime Server 2/3 (?server=sm / ?server=otaku) lengkap dengan daftar server alternatif.
GET /api/v1/{sokujaId|sakunime}/resolve/:malId
SDK: provider.resolveMalId(malId)

Test direct resolution from a MAL ID to the matching Sokuja ID or Sakunime slug along with confidence score and alternative server matches: Menguji resolusi langsung ID MAL menjadi slug Sokuja ID maupun Sakunime beserta skor kecocokan dan daftar server alternatif: 

curl http://localhost:3000/api/v1/sokujaId/resolve/52991
curl http://localhost:3000/api/v1/sakunime/resolve/52991
